# Technology Expert Lab — 선에서, 빛까지

13번 장표(스크롤로 훑는 Blender 영상 위의 글과 3D 라벨)를 벤치마킹해 만든 **가상의 하이엔드 건설사 홈페이지**입니다.
발표 덱(`deck/`)이나 다른 사이트(`astra-site/`)를 건드리지 않는 독립 프로젝트입니다.

```bash
cd opus-site
npm install
npm run dev        # http://localhost:5200
```

## 영상 만들기

영상 프레임 묶음(`public/film/1920`, `public/film/1280`)은 용량 때문에 **저장소에 넣지 않았습니다**.
저장소만 받으면 페이지는 영상 대신 장마다의 정지 이미지(`public/film/poster`)를 보여 주고, 나머지는 모두 동작합니다.
영상까지 보려면 아래 순서로 렌더한 뒤 인코딩합니다(M4 Max 기준 약 1시간 반).

```bash
blender -b --python tools/render-film.py -- --mode layout                   # 장마다 구도 확인(렌더 없음)
blender -b --python tools/render-film.py -- --mode still --scale 40         # 여덟 정지 지점 미리보기
blender -b --python tools/render-film.py -- --mode final --hd               # 2560×1440 전체 프레임 → render/film/frames
blender -b --python tools/render-film.py -- --mode track                    # 라벨 좌표만 → src/film/track.json
blender -b --python tools/render-film.py -- --mode shot --hd --samples 192  # 프로젝트 사진 → render/film/shots
python3 tools/grade-stills.py render/film/shots public/projects             # 사진 마감(톤·비네트·입자)
tools/encode-film.sh                                                         # 낱장 WebP(render/film/webp) → 묶음(public/film) + 정지 이미지
```

장면은 한 스크립트가 모두 만듭니다: 강변 대지, 측량선(선마다 그려지는 구간을 가진 발광 재질), 말뚝과 매트 기초,
층마다 1.2°씩 도는 48층 타워(코어·기둥·슬래브·커튼월·실내가 Geometry Nodes로 한 층씩 드러남), 코어 안에서 오르는 타워 크레인,
자동 상승 방호벽, 토탈스테이션 레이저, 강 양쪽 도시(밤이 깊을수록 창이 줄고 따뜻해짐), 사장교, 미술관, 톱날 지붕의 연구 캠퍼스.
프레임 사이의 모든 움직임은 정지 지점에서 속도가 0이 되도록 구워 두어, 스크롤을 멈춘 화면이 흔들림 없이 선명합니다.
타워 제원은 `src/twin/tower.json`으로도 내보내 디지털 트윈이 같은 값을 씁니다.

## 기술

React 19 · TypeScript · Vite 7 · three.js(디지털 트윈, 가까워질 때 불러옴) · Lenis(부드러운 스크롤).
글꼴은 Pretendard(한글·본문), Archivo(넓은 영문 제목·숫자), Martian Mono(계기판)이며 모두 SIL OFL로 저장소 안에 들어 있습니다.

영상 프레임은 성긴 순서(16칸마다 → 8 → 4 → 2 → 1)로 받아 첫 묶음(44장, 2.5 MB)만 오면 페이지가 열리고, 나머지는 스크롤하는 동안 채워집니다.
프레임은 해상도(1920·1280)마다 그 순서대로 이어 붙인 묶음 다섯 개(`pass0~4.bin`)와 위치표(`index.json`)로 저장해 두었고(`tools/pack-film.py`),
페이지는 묶음을 스트리밍하면서 한 장 분량이 도착할 때마다 꺼내 씁니다. 저장소에는 낱장 1,362개 대신 파일 12개만 들어갑니다.
풀린 비트맵은 26장만 캐시합니다. 없는 파일을 `index.html`로 돌려주는 서버에서도 JSON·묶음이 아닌 응답이면 정지 이미지로 바꿉니다.

## 사실과 가상

Technology Expert Lab과 이 사이트의 프로젝트, 공정 기록, 수치는 콘셉트 웹사이트를 위해 만든 **가상의 내용**입니다(푸터에 명시).
타워의 치수·층수·비틀림·바닥 면적·커튼월 유닛 수처럼 모델에서 나오는 값은 렌더 스크립트의 제원과 같습니다.
공정일, 오차, 간섭 건수, 시운전 기간 같은 운영 기록은 연출용 가상 수치입니다.
