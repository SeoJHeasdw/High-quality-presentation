# 작업할 때 필요한 규칙

판단 기준은 `LESSON-SHAPE.md`와 `VIDEO-PACING-GUIDELINES.md`다.
이 문서는 구현 함정을 모은다.

## 작업 경계

- 사용자의 현재 요청이 범위와 금지 사항을 정한다. 다른 작업자의 변경은 보존한다.
- 화면과 대본은 안정적인 화면 ID로 연결한다. 비운 ID는 재사용하지 않는다.
  번호는 삽입 때 바뀐다. `where`로 현재 번호를 ID로 풀고 이후 검사는 ID를 따른다.
- 레슨 파일의 `NN-` 순서와 챕터 인덱스 머리의 의도를 함께 확인한다.
  명시적 import/spread는 그 배열 순서가 기준이다.
- CSS를 챕터 이름만으로 분리하는 리팩터링과 픽셀 기준 이미지 회귀 테스트는 기각됐다.
  필요한 렌더러·CSS 위치와 공유 영향은 `where -- <화면ID> --deps`로 찾는다.
- 기존 출처 검증과 기각된 경고는 새 근거 없이 다시 상정하지 않는다.
- 도구가 띄우는 수치와 `sceneCut` 선언은 수정 명령이나 품질 점수가 아니다.
  새 실물은 설명에 필요한 근거일 때 사용한다. 공개 자료는 직접 확보할 수 있다.
  로그인·계정이 필요한 자료는 사용자에게 필요한 URL과 부분을 설명한다.
- 새 파서·데이터 형식은 기존 텍스트 파서와도 맞아야 한다. 도구 변경 뒤에는
  `lint:offline`으로 확인한다.
  주석에는 현재 규칙을 쓰고, 과거 수치와 변경 이력을 반복해 적지 않는다.

## 화면과 전환

- 모션은 설명과 연결될 때 기능이다. 진입 후 무엇이 남고 실제로 무엇이 변하는지 본다.
  무한 모션이 없다는 `·` 표시만으로 정지감이나 결함을 판정하지 않는다.
- 정지감 완화의 기법·속도·반복 기준은 `VIDEO-PACING-GUIDELINES.md` §10을 따른다.
  승인된 내용과 기존 공간 안에서 값·조건·자료를 진행하고, 보조 효과는 실제 대상 범위에 둔다.
- `sceneGroup()`과 `SOLO_SCENES`·`SOLO_FAMILIES`가 DOM 유지 경계를 정한다.
  DOM 유지와 주된 그림 유지는 다르다. 판 교체·초점·카메라 이동을 구분한다.
- 연속 동작 사이에 다른 레이아웃을 끼우면 흐름이 끊긴다. 설명을 마친 뒤 근거를 보고
  돌아오는 컷은 가능하며 복귀 상태와 전환을 검수한다.
- 묶인 씬은 꺼짐 쪽에 전환을 걸지 않는다. `[data-on="true"]` 등 켜짐 규칙에만 둔다.
  기본값이 보이는 요소는 꺼짐 규칙에 `transition: none`을 둔다.
- 상태 속성은 `x || undefined`로 꺼졌을 때 제거한다. 벤더의 광역 `[data-on]` 등
  선택자가 속성이 남은 요소에 전환을 다시 걸 수 있다. `animation`은 `transition`을 이긴다.
- 자동 audit의 frame·safe·overflow·overlap·dead와 ghost는 실제 가시성을 확인할 후보다.
  알려진 오탐 ID 밖에 있다는 이유만으로 확정 오류로 바꾸지 않는다.
  액자 밖에서 잘린 요소와 의도적으로 교체되는 판을 확인한다.
- 색 언어는 파랑=기계, 금색=사람과 결론, 빨강=사실이 아님이다.
  앵커 그림은 유지하고 옆 글과 초점으로 설명을 진행한다.
- `definition`은 용어 판과 문장 착지에 함께 쓰인다. 렌더러의 `definitionTone`이
  문장 제목을 `statement`와 같은 크기로 맞춘다. 이름만 보고 새 판을 추가하지 않는다.

## 비교 화면

`comparison`·`split`·`case`는 스텝 0부터 왼쪽이 켜진다. 0=왼쪽, 1=오른쪽, 2=둘 다.
도입은 왼쪽 설명과 같은 대본 블록에 넣는다. 스텝 개수가 같아도 말과 초점은 어긋날 수 있다.

## 대본 편집

- 레슨 또는 대본 점검은 `where`로 번호를 풀고 `lessons`로 연속 대본을
  먼저 읽는다. 교육 설계 기준은 `LESSON-SHAPE.md` §12다. 문장 교정·스텝 수 일치만으로
  초심자 이해가 검증되었다고 보고하지 않는다.
- `## 화면ID` 아래 `### 0`부터 연속된 스텝을 적는다. `steps + 1`과 대본 상태 수가 같아야 한다.
  개수만 맞추지 말고 해당 순간의 명사·숫자·초점과 실제 대본을 대조한다.
- “제 해석이 아닙니다” 같은 방어적인 문장을 넣지 않는다. 출처는 화면이 댄다.
- 정의 없는 뒤 챕터 용어와 “이건 N장에서 다시” 예고를 넣거나 복원하지 않는다.
- 대본 예산은 글·초점·의미의 변화 강도로 정한다. `VIDEO-PACING-GUIDELINES.md` §0-1이 정본이다.
- 회상은 학습자의 선택과 정답 공개를 함께 확인한다. 질문을 듣기 전에 답이 보이면
  회상이 성립하지 않는다. 물음표와 ‘멈추’라는 단어만으로 인정하지 않는다.

## 자동 영상

`layout: "video"`는 무음 클립을 경로로만 지정한다. 편집점과 말의 동기화는
리허설에서 눈과 귀로 맞춘다.
