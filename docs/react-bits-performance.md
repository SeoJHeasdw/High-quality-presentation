# React Bits 인터랙션 적용

저장소에 가져온 `react-bits/src/ts-default`의 소스를 사용했다. 패키지를 통째로 실행하거나 새 의존성을 설치하지 않고 필요한 컴포넌트만 발표 앱에 가져왔다. 원본의 MIT + Commons Clause 고지문은 `deck/src/reactbits/LICENSE.md`에 보존했다.

| 장표 | 원본 컴포넌트 | 발표 중 동작 |
| --- | --- | --- |
| 4 | RippleDistortion | 2031년 화면 위에서 움직이거나 클릭하면 약한 굴절과 짧은 파문이 생긴다. Tab으로 선택한 뒤 Enter·Space로도 파문을 만들 수 있다. |
| 17 | TiltedCard · GlareHover | 결과물에 마우스를 대면 기울기와 광택이 변한다. 클릭·Enter로 크게 열고, Escape로 닫는다. 확대 중에도 방향키로 발표를 이어갈 수 있다. |
| 28 | PixelTransition · DecryptedText · MatrixHeadline | 제목이 한 글자씩 해독되며 나타난다. 얼굴 위를 가리키면 확대된 픽셀과 조준 표시가 따라온다. 클릭하면 얼굴을 픽셀로 덮었다 다시 구성한다. |

| 33 | PixelTransition · DecryptedText | 합성물 위에서 출처·동의에 대한 질문을 드러내고, 이미지들을 펼친다. 클릭해 고정할 수 있다. |
| 38 | TrueFocus | "만들기"와 "맡기기" 사이를 가리키거나 Tab으로 옮기면 초점 테두리가 이동하고, 초점이 간 쪽으로 아침빛의 색(금색·푸른색)이 바뀐다. 클릭·Enter로 선택한다. 두 선택지의 설명은 계속 읽을 수 있다. |
| 공통 | ClickSpark | 클릭한 위치에서 짧은 방사형 선과 원이 퍼진다. 1번 표지와 18~22번 영상에는 적용하지 않는다. |

1번은 사용자 리뷰에 따라 React Bits 적용 전의 표지로 되돌렸다. 18~22번의 영상·카메라·전환은 변경하지 않았다. 전체는 38장·69단계이며 포인터 조작은 추가 시연이다. 방향키만으로도 기존의 모든 내용에 도달한다.

4번은 굴절 강도를 0.18에서 0.055로 줄이고 클릭 파문 크기·굴절 색분리·소용돌이·잔상도 함께 줄였다. 28번 제목은 한 번 완성되면 멈추며 R로 다시 시작한다. M으로 완성 상태를 표시한 뒤 모션을 다시 켜도 제목을 반복 재생하지 않는다.

## 발표 환경에 맞춘 수정

- 화면은 1920×1080 무대를 CSS로 확대·축소한다. 포인터와 초점 테두리의 좌표를 이 배율에 맞춰 변환했다.
- M, 운영체제의 모션 줄이기, 숨겨진 브라우저 탭에서는 새 모션을 정지한다. 기본 내용과 클릭·키보드 조작은 유지한다.
- 클릭 효과와 물결 굴절은 실제로 움직이는 동안만 프레임을 계산한다. 떠난 장표의 이벤트·타이머·GPU 자원을 정리한다.
- WebGL을 쓸 수 없을 때 4번은 같은 정적 그림을 표시한다. 텍스트는 캔버스 밖에 있어 계속 읽을 수 있다.
- 확대 창은 기본 버튼과 dialog를 사용한다. 닫으면 원래 버튼으로 초점을 돌려준다.

검사: `npm run check:keynote`, `npm run check:performance`. 검수 화면과 입력 시연은 `deck/render/performance/`에 저장한다.
