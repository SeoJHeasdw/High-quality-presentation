# JAVIS / 제가 살아가려는 방식

Technology Expert Lab 팀과 나누는 30년 생존 실험. 46장, 94개 발표 단계로 구성한 16:9 브라우저 발표다.
일반 설명은 숫자·비교·도해와 실제 결과물로, 대상 이동은 발표자가 누르는 큐로 표현한다. 표지와 Factory 연속 장면에는 공간 연출을 쓴다.

## 실행

```bash
npm install
npm run dev
```

- [발표 화면](http://localhost:5180/#keynote)
- [발표자 대본](http://localhost:5180/#keynote/present)
- [이전 기술 강의](http://localhost:5180/#course)

`→` / `Space`: 다음 단계, `←`: 이전 단계, `숫자 + Enter`: 장표 이동.
`F`: 전체화면 켜기/끄기, `Esc`: 전체화면 종료, `H`: 조작 바 켜기/끄기, `M`: 모션 정지, `R`: 현재 장면 재시작.
발표자 창은 같은 브라우저에서 열어야 동기화된다.

`W`: 화면 드로잉 켜기, `Esc`: 드로잉 닫기. 켜진 동안에는 이동을 포함한 키보드 조작과 휠이 잠긴다. 상단 도구 막대에서 펜 색·두께, 네모, 텍스트, 지우개, 전체 삭제를 고른다. 텍스트 도구를 고른 뒤 원하는 곳을 더블클릭해 입력하고, 바깥을 클릭하면 확정된다. 텍스트 입력창은 내용에 맞춰 가로로 넓어지고 장표 끝에서는 줄바꿈하며, 높이도 자동으로 늘어난다. 닫으면 메모가 화면에서 사라지고, 같은 장표에서 다시 켜면 그대로 나타난다. 스텝을 넘겨도 유지되지만 장표를 앞이나 뒤로 넘기면 메모가 영구 삭제된다. 새로고침하거나 페이지를 닫으면 복원되지 않으며, 로컬 서버 연결이 끊겨도 임시 메모를 지운다. 발표자 창에서 `W`를 눌러도 발표 화면의 드로잉 모드가 같이 켜지며, `Esc`로 닫을 수 있다. 전체화면에서는 `Esc`가 드로잉이나 확대 이미지를 먼저 닫고, 다음 `Esc`가 전체화면을 닫는다.

4·23·35·39·40·46번에는 React Bits 기반 포인터·클릭 연출이 있다. 1번은 원래 표지로 유지한다.
23번 이미지는 클릭하면 크게 열리고 Escape로 닫힌다. 확대 중에도 방향키로 발표를 이어갈 수 있다.
적용 컴포넌트와 조작법은 [인터랙션 기록](../docs/react-bits-performance.md)에 있다.

## 서비스 시연 방식

본편은 **29~31번에 담은 실제 결과물을 장표 진입 시 자동 재생**한다. 29번과 31번은 화면이 나타난 뒤 1초 쉬고 시작한다. `P`는 재생/일시정지,
`A`는 소리 켜기/끄기다. 29번 강의와 31번 음악은 소리가 켜진 상태로 시작하고 30번 프리비즈는 무음 원본이다.
다음 장으로 이동하면 이전 미디어는 종료된다. 브라우저가 소리 자동 재생을 막으면 장표의 재생 버튼을 누른다.
음악은 `Shine on Me (햇살)` 전체 곡 30초 WAV다.

29~31번 오른쪽 아래의 **TTS / Assets / Music 엔진 실행** 버튼으로 실제 앱을 연다.
버튼을 누르면 미디어를 일시정지하고 전체화면을 빠져나온 뒤, 터미널에서 해당 엔진 루트의
`./app.sh`를 실행한다. 초기 준비와 실행 로그는 열린 터미널에서 확인한다.
버튼은 macOS의 로컬 발표 서버(`npm run dev` 또는 `npm run preview`)에서 동작한다.
서버 설정을 바꾼 뒤 이미 켜져 있던 서버에는 재시작이 필요하다. 정적 파일만 배포한 화면에는 실행 서버가 없다.
`demo-launchers/TTS.command`, `Assets.command`, `Music.command`를 직접 열어도 같은 앱을 실행한다.

24번부터 →로 진행하면 각 장면의 영상이 한 번 재생되고 마지막 화면에서 멈춘다.
21→22는 중앙 화면을 통과해 강의 화면으로 들어가고, 22→23은 화면 프레임을 맞춰 이미지 장면으로 바뀐다.
23→24는 화면을 가로지르는 물체 뒤에서 탑뷰로 전환하고, 24→25는 원반의 중앙을 통과해 전체 결과물을 보여준다.
←는 이전 장면의 마지막 화면을 보여준다. M으로 모션을 끄면 마지막 화면을 바로 표시하고, 다시 켜도 이미 끝난 장면을 재생하지 않는다. R은 현재 영상을 처음부터 재생한다.

Blender 원본 렌더 도구는 `tools/render-factory-film.py`, 배포용 영상과 마지막 화면은 `public/factory-film/`에 있다.
26번에 쓰는 청록색 새는 이 발표를 위해 Local Assets Engine으로 새로 생성한 2D 이미지다.
이미지 원본·프롬프트·모델·시드는 `public/engines/factory-assets/hero.json`에 있다. 기존 출력이나 엔진 코드는 변경하지 않았다.

23번의 미리보기도 실제 강의 캡처, 새 이미지가 등장하는 장면, 음악 파형 장면으로 맞췄다.
34~41번은 어두운 방과 붉은색(덱의 색 규칙에서 빨강 = 사실이 아님)으로 분위기를 바꾼다(`src/keynote/abuse/`).
37번 두 번째 단계에서 같은 말을 LoRA 강도 0·0.5·1.0으로 만든 목소리가 1초 간격으로 겹치고, 같은 목소리가 3반음 낮고 느리게 "엄마. … 나, 제호 아니야."라고 마지막 말을 한다(Qwen3-TTS + LoRA 0.6, `threshold-final-line.m4a`). 가상 음성 연출이며 38번의 통화 장면은 그대로 유지한다. 음성 아래에 Python으로 합성한 소리를 깐 12.4초 큐(`threshold-scene.m4a`)를 재생한다: 벽이 가라앉는 쿵 소리와 군중의 낮은 압력(0~1.7초) → 겹치는 목소리 아래 단2도·트라이톤 드론이 반음 올라가고 심장 박동이 빨라짐 → 컷과 0.7초 정적(귀울림만) → 고역을 깎은 마지막 말과 어두운 잔향. 원본 음성은 `threshold-voices.m4a` 그대로이고, `python3 tools/render-threshold-sound.py`(기본 strong, `--final-pitch`·`--final-tempo`로 마지막 말 조정)로 다시 만든다. P는 재생·일시정지, A는 음소거다. 제작 기록은 `public/abuse/audio/threshold-voices.json`에 있다.
34번은 장표 진입 뒤 약 1.35초 쉬고 영어 내레이션 샘플을 자동 재생한다. 제공받은 `english-narration-sample.m4a`의
앞 22.5초를 제거해 “First”부터 끝까지 약 59.1초 재생하며, 파형과 영어 문장은 이 샘플에 맞춰 표시한다.
다음 단계에서 "저는 이 문장을 녹음한 적이 없습니다"로 붉게 바꾸고, 제 목소리 어댑터의 실제 학습 기록
(12.3분·35.3초·약 67MB)과 공개 모델의 "3초" 설명을 놓는다. P는 재생·일시정지, A는 소리다.
35번은 붉게 물든 픽셀 얼굴, 36번은 지금의 제작 과정, 37번은 네 개의 벽(생성·확인·수정·연결)이 무너지며 검은 군중이 다가오는 도식이다.
38~39번은 Blender로 렌더한 한밤중 협탁 위 휴대전화 한 대(`public/abuse/night-phone.jpg`)에서 이어진다(묶음 night-phone).
새벽 2시 47분 모르는 번호의 전화 → 받으면 카메라가 휴대전화로 다가가고 실시간 자막으로 "엄마… 나야" → "합성된 목소리" 도장 →
같은 밤의 음성 메시지와 "지금부터는 저만 믿으세요". 휴대전화 화면은 DOM이며, 렌더가 내보낸 화면 네 모서리(`night-phone.json`)에 matrix3d로 얹는다.
38번 수신 시 짧은 진동음(WebAudio)이 두 번 나고, `→` 또는 휴대전화의 응답 버튼을 누르면 통화 단계로 넘어가 가상 합성 음성이 한 번 재생된다. 39번 음성 메시지도 장표 진입 시 한 번 재생된다. A는 음소거, P는 재생/정지다.
두 음성은 Qwen3-TTS와 발표자 본인의 LoRA 어댑터(0.60)로 만들었으며 실제 다른 사람의 목소리를 흉내 내지 않는다. 제작 기록은 `public/abuse/audio/manifest.json`에 있다.
40번은 모자이크한 사진 한 장이 두 배씩 늘어 화면을 채우고, 원본을 지워도 사본이 남는다.
41번은 같은 휴대전화에서 끊고 저장된 번호로 다시 거는 확인 방법(FTC 권고)으로 끝난다. 모든 통화·메시지·사진은 가상 상황이다.
배경 이미지의 생성 기록은 `../docs/abuse-art.md`에 있다.
42번은 붉은 방이 아니라 완전한 검정 위의 파랑과 금색이다(`src/keynote/leash/`). 첫 단계는 41번과의 이음새다: 41번 휴대전화 자막 자리에
가짜 아들의 말 네 줄이 붉은 입자로 떠 있다가 풀리며 파랑이 되어 흩어지고, "목소리는 가짜였지만, 사람을 움직인 건 말이었습니다"(42-0).
그 자리에서 사람을 움직여 온 낱말(약속·설득·거짓말·prompt…)이 떠올라 흘러와 사람의 형태가 되고(42-1), 금색 고리가 목을 감으려 좁혀지다가 끝내 닫히지 않고 벌어진다(42-2). 실루엣은 외부 이미지 없이 캔버스에 직접 그려 입자로 샘플링한다.
43~46번은 한 묶음(finale)이다(`src/keynote/finale/`). 15번의 집을 시간대만 바꿔 다시 렌더한 푸른 새벽(43~45, 흐리게)과 해 뜨는 아침(46)이 뒤에 깔리고,
42번도 이 묶음의 첫 장이라 42번의 3D 장면(`leash/world.ts`)이 43번 첫 단계까지 같은 캔버스로 이어진다. 장이 바뀌어도 화면이 깜빡이지 않는다.
43번 첫 단계에서 42번 끝의 입자 몸과 닫히지 않은 금색 고리가 그대로 있다가, 고리가 풀려 떨어지고
입자가 금빛으로 옮겨 가 집을 짓고, 그 아래로 새벽 집 렌더가 떠오른다(43-0, "제가 할 수 있는 건 제 집을 짓는 일입니다"). 다음 단계에서 흐린 배경과 세 겹의 표로 넘어간다(43-1).
46번에서 배경이 선명해지며 아침으로 밝아진다. 43번은 위로 지나가는 모델(지금 Qwen3-TTS, 이후는 가정)과 아래에 쌓이는 작업 방식·판단의 기록·결과물의 세 겹,
44번은 local-tts-engine 결정 기록에서 뽑은 실제로 잘 안됐던 과정 여섯 줄과 동의 확인 약속이다.
45번은 새벽 하늘 위에 투명한 3D 캔버스를 얹은 설계도다(`finale/blueprint.ts`, 다섯 단계). 15번의 청사진 격자에서 방이 솟는다: 지어진 방 TTS·ASSETS·MUSIC(개발 중)과
RICE·Personal CIO(만듦), 점선의 Agent OS(구상) → 다섯 방의 모든 짝이 빛으로 이어지고 왼쪽에 "이론상 이을 수 있는 조합" 26, 실제 예 두 가지는 금색(가능성) →
사무직이었다면 만들었을 점선 방 네 개(가정)가 하나씩 서며 앞의 모든 방과 이어지고 숫자가 502로 → 카메라가 물러나며 현관(나)에서 뻗은 거리를 따라 방이 40개까지 번지고 숫자는 약 1.1조 →

## 근거와 범위

출처 링크는 해당 장표 아래와 대본에 있다. `FACT-CHECK.md`에 수치의 범위와 확인되지 않은
주장을 정리했다. Cloudflare 비중은 2025.12.02 HTML 요청의 예시이며 현재 인터넷 전체의
고정 비율이 아니다. 가격 전략은 발표자의 가설로 표시한다. Jev 응답 시간과 가격은 개발사가 발표한 값이다.

17·21·32·42·45번에 새로 쓴 인용과 수치(머스크 원문, MIT 83%, 영수증 두 장, Compound AI System, 케빈 웨일, a16z 10배, Gemini Robotics, RICE·Personal CIO)의
원문과 조건은 `FACT-CHECK.md` 마지막 표에 있다. 발표자의 질문·판단·가정·가능성은 화면에 그렇게 표시한다.

저장된 미디어 원본과 발췌 위치는 `public/demos/provenance.json`에 기록했다.
원본 엔진 저장소와 기존 생성물은 수정하지 않았다. 인터넷 연결은 외부 원문·리플레이 링크를
누를 때만 필요하고, 본편의 폰트·사진·영상·음원·시각화는 로컬에서 재생한다.

## udemy-agent와 차별점

- **장표가 훨씬 적다.** 798장 → 28장. 온라인 얼굴없는 강의는 화면이 말을 다 해야
  해서 장표가 기하급수적으로 늘지만, 이 강의는 사람이 직접 말하는 오프라인이라
  화면은 결론 한 줄만 들고 설명은 화자가 한다.
- **글자가 적다.** 한 화면 1주장+1근거를 더 빡세게 지킨다. 청중은 화면을 읽는 게
  아니라 화자를 보면서 한 귀를 화면에 둔다.
- **애니메이션은 살린다.** 오프라인이라고 정지 장표로 가지 않는다. 스텝 순차공개,
  금색 metric(ShinyText), 가운데 정렬 착지를 전 장에 깔아 화면이 계속 살아 있다.
- **실물은 시연 자리다.** TTS 파이프라인 등은 화면에 결과를 한 줄만 두고 과정은
  현장 시연과 말로 한다.
