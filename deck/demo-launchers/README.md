# 현장 시연

본편은 덱의 23~25번에 넣은 실제 결과물로 진행한다.
P로 재생, A로 소리를 켠다. 스피커 확인은 발표 전에 한다.
Music의 15초 음원은 개발 후보이며 최종 청취 승인본이 아니다.

질문이 들어와 앱을 더 보여줄 때만 해당 .command 파일 하나를 연다.
TTS와 Assets는 기존 app.sh, Music은 기존 npm run start:app을 사용한다.
이 실행 파일들은 새 생성이나 모델 다운로드를 직접 요청하지 않는다.
앱 내부의 초기 준비가 필요한 환경에서는 원래 앱 실행 절차를 따른다.

세 엔진을 동시에 생성 작업에 사용하지 않는다. 저장된 결과와 편집 흐름 위주로 보여준다.
원본 프로젝트나 기존 결과물은 수정하지 않았다.
