## manifesto-system
### 0

### 1
만드는 일은 Factory에 맡깁니다. 필요한 엔진이 음성을 만들고, 자막과 장표를 붙여 영상으로 내놓습니다. 지금은 이런 제작 엔진들을 먼저 만들고 있습니다.
### 2
저는 완성된 영상을 보고 듣습니다. 발음이 틀린 곳을 짚고, 그 부분을 다시 만들어달라고 합니다. 마음에 들면 고르고요. 이렇게 맡기고 고치는 일을 한곳에서 이어가고 싶습니다. 그럼 Factory 안을 들여다보겠습니다.

개발 상태: Agent OS와 Factory를 연결한 전체 흐름은 만들고 싶은 구상입니다. 제작 엔진들은 현재 별도 프로젝트로 개발 중입니다. 화면에서 Agent OS는 점선과 '구상', 엔진은 '개발 중'으로 표시합니다. 고리 위의 결과 화면은 실제 강의 영상의 한 장면입니다.

## manifesto-factory
### 0
Factory 안은 이렇게 생겼습니다. 일마다 맞춘 모델이 제 컴퓨터에서 대기하고 있습니다. 목소리는 Qwen3-TTS에 제 목소리 어댑터를 붙였고, 받아쓰기 검수는 다른 계열인 Whisper가 맡습니다. 이미지와 3D, 음악, 그리고 업무 에이전트 RICE까지 각자 자기 모델이 있습니다. 요청이 들어오면 맞는 스테이션 하나만 켜집니다. 그리고 위에 따로 떨어진 문이 하나 있습니다. 프론티어 모델입니다. 어려운 판단이 필요할 때만 이 문으로 올라갑니다. 요청을 알아서 나누는 부분은 아직 구상이고, 지금은 제가 나눠서 맡깁니다.

근거: 각 엔진 README의 제작 모델. 목소리 Qwen3-TTS 1.7B Base + jaeho-ko-r16-v1 LoRA 0.60(local-tts-engine), 받아쓰기 검수 Whisper large-v3-turbo MLX FP16(docs/QUALITY.md, DECISIONS.md 2026-09-03), 이미지 FLUX.2 klein 4B·3D TRELLIS.2(local-assets-engine), 음악 ACE-Step 1.5(local-music-engine), RICE는 Ollama의 qwen3.6:35b-a3b-q4_K_M(2026-09-21 촬영 화면, 사용자가 Claude와 Ollama 중 고른다). 자동 라우팅은 구현되지 않았습니다.
### 1
그렇다고 프론티어 모델을 안 쓰는 게 아닙니다. 많이 씁니다. 이게 이번 달 제 영수증입니다. Codex를 쓰는 요금제가 월 15만 9천 원이고, Claude는 이번 달 추가 사용량만 72달러 77센트입니다. 둘만 더해도 디지털 월세가 한 달에 20만 원이 넘습니다. 이건 거의 다 이런 도구를 만드는 데, 코딩 에이전트에 쓴 돈입니다. 만드는 데만 이만큼 나갑니다. 그러니 매일 반복하는 생산까지 비싼 모델에 맡길 수는 없죠. 비싼 지능은 판단에만 빌려 쓰고, 생산은 제 컴퓨터에서 소유합니다.

### 2
그래서 공장입니다. 각자 자기 일만 합니다. 이런 구조를 연구자들은 Compound AI System이라고 부릅니다. 모델 하나가 아니라 여러 모델과 도구가 나눠 맡는 AI 시스템이요. 버클리 연구진이 2024년에 이렇게 이름을 붙였습니다. 비싼 모델과 싼 모델 사이에 요청을 나누는 일은 LLM 라우팅이라고 하고요. 새 일이 생기면 스테이션을 하나 더 들이면 되고, 더 좋은 모델이 나오면 그 자리만 바꾸면 됩니다.
