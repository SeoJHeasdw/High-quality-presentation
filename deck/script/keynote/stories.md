## story-brood

## story-bots
### 0
게임 밖으로 나와서 인터넷을 보면, 방문의 의미도 바뀌고 있습니다. Cloudflare의 공식 분석에서 2025년 12월 2일 HTML 요청 중 사람의 비중은 47%였습니다. 나머지 53%를 자동화된 요청으로 표시했습니다. 이건 전 세계 사람 수나 인터넷 사용 시간의 비율이 아니라, Cloudflare 고객 사이트의 웹페이지 요청 관측입니다.
### 1
여기서 모든 봇을 AI 에이전트라고 부르면 안 됩니다. 검색 수집기 등 다른 봇도 있습니다. 그래도 앞으로 내 대신 에이전트가 읽고 비교하는 일이 많아진다면, 웹사이트가 먼저 설득해야 하는 상대도 달라질 수 있습니다. 그게 제가 흥미롭게 보는 부분입니다.

출처: https://blog.cloudflare.com/radar-2025-year-in-review/
HTML traffic shares by bot type 절. 2025.12.02 사람 47%, non-AI bots 44%, Googlebot 5%. 전체 자동화 53%는 100-47의 보수 계산이며 반올림된 비중입니다. 전체 콘텐츠 유형을 집계하는 Radar 비율과 섞지 않습니다. 2026년 현재의 고정 비율로 제시하지 않습니다.

### 0

출처: https://openai.com/index/hugging-face-incident-and-the-road-ahead/
피해 서비스의 공개 확인: https://huggingface.co/blog/security-incident-july-2026

## story-jev
### 0
또 하나는 속도입니다. TypeSafe AI가 발표한 Jev는 길게 문장을 쓰는 대신 프로그램이 바로 쓸 판단 값을 돌려주는 모델입니다. 개발사가 제시한 응답 시간 범위는 70에서 500밀리초입니다. 특정 환경에서의 개발사 측정이라는 조건은 같이 봐야 합니다.
### 1

출처: https://typesafe.ai/blog/introducing-system-one-models-and-jev (2026-09-15)
공식 시연에는 Doom과 Wikiracing이 포함됩니다. 실시간 주식 트레이딩은 여기서 발표자의 응용 가설이며, 실제 거래나 수익 검증 사례로 표현하지 않습니다.
