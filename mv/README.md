# 뮤비 시안

`감성 힙합 초안` 3분에 맞춘 모션그래픽 뮤직비디오 시안이다. Blender 없이 브라우저 캔버스로 그리고, 아직 장표에는 넣지 않았다. 발표 덱(`../deck`)과는 코드가 섞이지 않고, 덱에는 렌더한 mp4만 쓴다.

기본은 **유화 뮤비 본편**(3분, 41컷)이다. 가사 없이 후드 쓴 아이의 연기로 이야기를 끌고 간다. 레퍼런스는 손그림 캐릭터의 연기와 남보라 밤·금빛 색감이다.
깨끗하게 그린 장면을 붓질 패스(`painter.ts`)가 다시 칠하고, 빛은 따로 그려 아이 뒤만 지운 뒤 더한다. 얼굴과 낙서(느낌표·하트·반짝이)는 붓질 뒤에 또렷하게 얹는다.
움직임은 초당 15장으로 끊고, 컷은 모두 마디 첫 박에서 바뀐다(구간이 바뀌는 큰 박자에는 번쩍임, 브레이크와 새벽은 검정으로 넘어간다). 화면에 글자는 넣지 않는다.

## 이야기

색은 덱의 규칙을 잇는다: 남보라 밤·차가운 빛(폰·번개) = 기계·세상, 금빛(나방·달) = 사람·마음. 달은 아이가 향하는 곳이다.

| 시각 | 사건 |
| --- | --- |
| 0:00 | 외로운 밤. 폰을 보던 아이가 유리를 두드리는 나방에 고개를 든다. 창이 열리고 나방이 쏟아진다 |
| 0:19 | 손끝에 나방이 앉는다. 창을 넘어 지붕을 걷고, 하늘에서 달을 발견한다 |
| 0:44 | 달을 손가락으로 재 보고, 도움닫기해 뛰지만 모서리에서 휘청, 엉덩방아. 폰을 꺼냈다가 나방이 화면에 앉는다 |
| 0:55 | 나방이 모여 달까지 **나방 사다리**를 놓는다(난간 둘, 발판 하나가 나방 한 마리). 한 걸음에 발판 하나씩 오르고(아래를 보고 휘청), 브레이크에 자기 방 창을 돌아보며 폰을 주머니에 넣는다 |
| 1:19 | 달이 실을 내려 준다. 실을 잡고 날아올라 도시의 창들을 스친다 |
| 1:36 | **같은 외로운 창의 친구.** 나방이 유리를 두드리고(0:05의 거울), 친구가 폰을 망설이다 손을 잡는다. 둘이 함께 구름을 뚫고 달 앞을 지난다 |
| 2:03 | 구름 위에서 쉰다. 구름 틈 아래로 마주 보는 두 창(둘은 길 하나 사이 이웃이었다) |
| 2:14 | 구름 징검다리를 함께 뛴다. 폭풍이 덮쳐 나방이 흩어지고, 친구가 떨어진다 |
| 2:25 | 아이가 뛰어들어 손을 잡는다. 어둠 속에서 둘이 폰을 켠다(차가운 빛) |
| 2:30 | 흩어졌던 나방이 그 빛을 보고 모여들어(따뜻한 빛) 둘을 받아 올린다. 폭풍을 뚫고 맑은 하늘, 달에 손이 닿는다 |
| 2:44 | 달이 터져 빛의 실이 도시로 흘러내리고, 창이 하나씩 켜진다(0:08의 박자) |
| 2:50 | 새벽. 빛 구슬을 안고 잠든 아이. 마주 보는 두 창에서 둘이 서로를 알아보고 손을 흔든다 |

`npm run render -- --ending tel`은 마지막 두 마디를 나방이 `Technology Expert Lab`을 이루는 장면으로 바꾼다(팀 시연용).

```bash
npm install           # 처음 한 번 (playwright, typescript)
npm run dev           # http://localhost:5185  Space 재생 · ←/→ 5초 · ↑/↓ 구간 · D 편집표
npm run render        # render/hiphop-mv.mp4 (1080p, 원곡 WAV 포함, 8코어에서 약 2분)
npm run render -- --jobs 8 --from 79 --to 123 --fade --out render/part.mp4   # 일부만
npm run render -- --still 15,93,175   # 그 시각의 PNG만 render/stills/
npm run typecheck
npm run analyze       # 곡을 바꿨을 때 public/hiphop-analysis.json 다시 만들기
```

`tools/analyze.py`가 곡에서 박(87.5 BPM)·마디·구간·프레임별 음량과 스펙트럼을 뽑는다. 화면은 시각 t만 보고 그리므로
실시간 재생과 mp4 렌더가 같은 그림을 낸다. 유화 본편은 프레임마다 붓질을 하므로 실시간 재생은 느리다. 덱에는 렌더한 mp4를 쓴다.

## 구조

```
mv/
  src/paint/
    film.ts      한 프레임의 순서(깨끗한 장면 → 붓질 → 빛 → 얼굴·낙서 → 전환)와 컷 모으기
    act1.ts … act5.ts   컷 목록. 막마다 한 파일(방·지붕 / 첫 도전과 다리 / 후렴·친구 / 구름·폭풍 / 새벽)
    hoodie.ts    아이와 친구의 뼈대(연속 값 자세·두 마디 팔·발이 땅에 붙는 걸음·표정)
    anim.ts      연기 도우미(키프레임 이징, 후드 끌림 스프링, 팔 자세 이어 붙이기, 점프, 걸음 거리)
    sky.ts       고흐풍 하늘·달·고리 별·소용돌이 구름
    world.ts     방·지붕(점프대)·골목·나방 사다리   world2.ts  구름 섬·폭풍·창가·친구의 방·들판
    kit.ts       나방·빛의 실·낙서·붓 점 궤적 같은 공용 재료   painter.ts  붓질 패스(소용돌이 붓결 포함)
  tools/        serve.mjs(미리보기 서버) · render.mjs(mp4) · analyze.py(곡 분석) · index.html
  public/       hiphop-analysis.json
  render/       결과물 (gitignore)
```

곡과 글꼴(`/demos`, `/fonts`)은 `../deck/public`을 그대로 가리킨다. 복사본이 없으니 곡 파일을 바꾸면 `npm run analyze`로 분석 JSON을 다시 만든다.

### 그림체를 지키는 규칙

- **붓질 뒤에 가는 선·매끈한 그라데이션을 얹지 않는다.** 붓질 뒤에 올리면 그림체와 따로 노는 "컴퓨터 그림"이 된다. 달·별은 고리 색 띠로, 점프 궤적은 굵은 붓 점(`dabLine`)으로, 사다리는 난간과 발판(`ladderPaint`)으로 깨끗한 장면에 칠해 붓질을 통과시킨다. 달 둘레의 붓결은 `swirls`로 돌린다.
- 빛(나방·빛의 실·번개·폰 불빛)은 따로 그려 가산 합성한다. 붓질을 거치지 않아도 되는 것은 이것뿐이다.
- 움직임은 `hoodie.ts`의 연속 값만으로 짠다. 팔·앉기·돌아보기를 문자열로 켜고 끄지 말고 `armsSeq`·`kf`로 이어서, 자세 사이가 튀지 않게 한다. 걷기는 `walker`/`walkDist`로 걸은 거리에서 위상을 얻어 발이 미끄러지지 않게 한다.
